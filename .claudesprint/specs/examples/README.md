# Example Specifications

For an example of a well-structured spec, see the demo spec:

```bash
claudesprint demo
```

This creates a URL Shortener project that demonstrates the full ClaudeSprint workflow.

## Writing Your Own Spec

1. Copy `../template.md` as a starting point
2. Place your spec in the parent `specs/` directory
3. Run `claudesprint init --spec YOUR_SPEC.md` to generate a sprint

## Spec Structure

A good spec includes:
- **Overview** - What you're building
- **Constraints** - Tech requirements and limitations
- **Deliverables** - High-level outcomes
- **Work Plan** - Issues with tasks and acceptance criteria
